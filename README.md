TaskMaster - Interactive To-Do List

​A modern, responsive To-Do List web application built using HTML, Tailwind CSS, and plain JavaScript.

​Features
​Task Management: Create, edit, complete, and delete tasks.

​Categorization & Priority: Assign priorities (Low, Medium, High) and categories (Work, Personal, Health, etc.).

​Due Dates: Set target dates with automatic overdue tracking.

​Filtering & Search: Instantly filter by status (All, Active, Completed) or search by keyword/category.

​Progress Analytics: Real-time stats showing total, pending, and completed tasks along with completion percentage.

​Local Storage Persistence: Automatically saves your tasks and preferences locally in your browser.

​Dark Mode: Integrated light/dark theme toggle that remembers your choice.

​Getting Started
​No installation or build setup required.

1. ​Clone or download this repository.
2. ​Open index.html directly in any modern web browser.

​Tech Stack
​HTML5: Structural markup
​CSS: Utility- styling 
​JavaScript (ES6+): Core logic, DOM manipulation, and LocalStorage integration
